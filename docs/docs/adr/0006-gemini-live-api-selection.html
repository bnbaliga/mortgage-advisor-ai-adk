ADR-0006: Gemini Live API for Voice AI

Status

Accepted

Date

2026-10-25

Context

We need to select a voice AI platform that supports: - Bidirectional streaming: Send and receive audio simultaneously - Low latency: Sub-second response times - Interruption handling: Stop speaking when caller interrupts - Function calling: Invoke tools during conversation - Natural voices: High-quality text-to-speech

Decision

We chose Google Gemini Live API with Google ADK (Agent Development Kit).

Key Selection Criteria

Criteria Gemini Live OpenAI Realtime Amazon Lex Weight
Streaming latency < 500ms < 500ms ~1s High
Interruption handling Native Native Manual High
Function calling Native Native Custom High
Voice quality Excellent Excellent Good Medium
ADK integration Native None None High
Pricing $0.01/min $0.06/min $0.004/15s Medium

Consequences

Positive

  • Sub-second latency: ~300-500ms typical response time
  • Native interruption: Gemini stops speaking immediately on barge-in
  • ADK integration: First-class tool calling, session management
  • Single vendor: Google Cloud for infrastructure + AI
  • Cost effective: $0.01/min vs $0.06/min alternatives

Negative

  • Google lock-in: Tightly coupled to Gemini ecosystem
  • Preview API: Live API still in preview (may change)
  • Limited regions: Not available in all GCP regions
  • Model limits: 100k token context window (requires compression)

Mitigations

  • Abstraction layer: ADK provides some portability
  • Preview monitoring: Track API changes, test against beta
  • Context compression: Slide window at 100k tokens → 60k
  • Regional deployment: Deploy in supported regions (us-central1)

Alternatives Considered

Option 2: OpenAI Realtime API (Rejected)

Similar bidirectional streaming with GPT-4.

Rejected because: - Higher cost ($0.06/min vs $0.01/min) - No native ADK equivalent - Separate vendor from infrastructure

Option 3: Custom STT + LLM + TTS (Rejected)

Compose Whisper + GPT-4 + ElevenLabs.

Rejected because: - Higher latency (3 round trips) - Complex orchestration - No native interruption handling

Option 4: Amazon Lex + Bedrock (Rejected)

AWS voice AI with Claude.

Rejected because: - Higher latency (~1s response) - Manual interruption handling - Less natural voice options
