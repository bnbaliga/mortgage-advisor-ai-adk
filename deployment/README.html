Deployment

This folder contains deployment configurations for the Mortgage Advisor Voice AI.

Files

File Description
Dockerfile Container image for Cloud Run deployment
docker-compose.yml Local development with Docker

Local Docker Development

# From project root
cd deployment
docker-compose up --build

Then open http://localhost:8000

Cloud Run Deployment

The CI/CD pipeline in .github/workflows/deploy.yml automatically deploys to Google Cloud Run on push to main branch.

Manual Deployment

# Build and push
gcloud builds submit --tag gcr.io/PROJECT_ID/mortgage-advisor

# Deploy
gcloud run deploy mortgage-advisor \
  --image gcr.io/PROJECT_ID/mortgage-advisor \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated
